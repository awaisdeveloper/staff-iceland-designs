Driving-licence category icons

A small, simple picture for every driving-licence category (AM through T), always shown together with its code and label. The same icon set is used wherever licence categories appear — a Candidate picking which categories they hold, and a Company picking which categories a role requires. The two pages below are the real, live forms with just that one change added, so you can see it exactly as it will look in place.

Candidate registration — Step 2

Personal details and eligibility

The real Step 2 form. Open the "Licence types" field to see every category with its icon, and two already selected (B, BE) so you can compare the selected vs. unselected look.
Company — Request Staff

Tell us who you need

The real public "Request Staff" form. The "Required licence categories" field shows the same icon set, with B and C already selected.

A few notes

  • Nothing here is built or live yet — this is a direction to react to, not a finished design.
  • Every icon always appears with its code and label — nobody has to recognise a picture alone.
  • Categories with a trailer ("E" suffix) reuse the base vehicle's icon plus a small trailer glyph, rather than a brand-new picture per combination.
  • Happy to try a different visual style (filled icons instead of line icons, a different icon set entirely, etc.) — this is just a starting point.
