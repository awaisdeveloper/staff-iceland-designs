Version 3 design concepts

Three modernized visual directions for the admin, candidate and company interfaces — each with a genuinely different layout skeleton (not just a different accent color), built on the real Staff Connection navy / blue / red brand palette, each with a working light and dark mode toggle.

How to compare: every design covers the same 8 screens with the same real data — a dashboard, an entity-level "List Employees" / "List Companies" table, the per-application "List Applications" tables, a registration edit form, the candidate portal, and a login screen. Use each page's own toggle button to check both light and dark mode.

1. Modern Minimal

Classic light sidebar + top bar SaaS layout, white shadow cards. The sidebar itself switches with the theme. Familiar and easy to scan for daily admin work.

No sidebar — a horizontal top bar that stays brand navy in both modes, bordered sharp-cornered cards, top-border accent stat blocks, Space Grotesk. Structured, technical, console-like.
