Recommendation

Option A (grouped list) is the one I'd build first. With ~8 regions and roughly 64 municipalities, a searchable, collapsible list is faster to scan and select from than tiles, works identically on mobile, and needs far less design/build time than a true map-based picker.

Option B shows what a more visual version could look like — region tiles instead of a map, since an actually accurate clickable map of Iceland is a much bigger build for little real gain here (there are only 8 regions; a map mostly adds visual flair, not usability). Happy to build B instead, or offer both, if preferred.
