Register as a candidate

This is the real registration form's field order and styling, with the work-area selection shown below in place of the old free-text "Preferred Work Location" field. Use the A / B / C switch to compare the three options.

Native multi-select. Cheapest to build, but selecting several areas needs Ctrl/Cmd-click (or long-press on mobile) — not obvious to most users.

Same dropdown component already used for Job Category / Shift Types on this form — ticking a region selects every municipality inside it.

Tap a region tile to select it whole, or refine to specific towns underneath.

Fields shown greyed-out/read-only are sample context from the real form, not editable here — only the work-area field is interactive. Municipality/region groupings are placeholders pending sign-off.
